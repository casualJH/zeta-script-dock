# 제타 스크립트 Dock

제타(zeta-ai.io)에서 여러 유저스크립트의 실행 버튼을 하나의 Dock에 모아 사용하는 Tampermonkey 스크립트입니다.

## 설치

**[제타 스크립트 Dock 설치 / 업데이트](https://raw.githubusercontent.com/casualJH/zeta-script-dock/main/zeta-script-dock.user.js)**

Tampermonkey가 설치된 브라우저에서 위 링크를 열고 설치하세요.

## 주요 기능

- 페이지의 플로팅 버튼을 자동 탐색하고, **선택한 버튼만** Dock에 추가
- 일반 버튼 및 접근 가능한 Shadow DOM의 아이콘 버튼 탐색
- Dock에서 원본 스크립트 기능 실행
- 버튼 이름·아이콘 변경, 추가·제외 및 원본 버튼 복원
- 편집 모드에서 드래그로 목록 정렬
- Dock 위치·설정 저장
- 동일한 플로팅 버튼 내부 요소의 중복 감지 방지

## 사용 방법

1. 제타 페이지에서 Dock 버튼을 누릅니다.
2. 편집 모드에서 발견된 버튼을 확인하고 원하는 항목만 **추가**합니다.
3. 일반 모드에서 항목을 눌러 해당 기능을 실행합니다.
4. Dock에서 빼고 싶은 항목은 편집 모드에서 제거하면 원본 버튼이 다시 표시됩니다.

> 새로 감지한 버튼을 자동으로 숨기지 않습니다. 기존 유저스크립트는 별도로 설치·활성화되어 있어야 합니다.
